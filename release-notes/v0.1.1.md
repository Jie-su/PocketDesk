# PocketDesk v0.1.1 · 手机重连修复

在 iPhone 上直接断开 UU，再次连接同一块 Windows 超级屏时，PocketDesk 以前可能停在等待恢复的状态，需要重启程序才能回到竖屏。现在确认新的手机连接后会重新尝试适配。iPhone 17 Pro 已实测断开再连可自动恢复到 1200×1920 竖屏。

如果 UU 已经还原屏幕，PocketDesk 会核对原显示状态并释放旧记录，不再重复切换分辨率。屏幕暂时不可读时仍保留记录；普通电脑接管也不会触发手机适配。

**下载与更新：** 在被控 Windows 电脑上正常结束工作台并退出旧版，下载 `PocketDesk-v0.1.1-win-x64.zip`，完整解压到新目录后运行 `PocketDesk.exe`。沿用桌面快捷方式时，请把目标改为新版程序。压缩包自带 .NET 运行时，无需另装；本预览版未签名。附件 `SHA256SUMS` 可用于核对下载。

**验证范围：** 本地 Windows 完整回归 199 项通过，其中新增 13 项。真机验证覆盖 iPhone 17 Pro 直接断开 UU 后重连；不代表所有手机型号或第三方应用窗口的原位恢复均已验证。
