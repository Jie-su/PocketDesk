# PocketDesk v0.2.0 · 手机工作台测试版

手机接入后默认收起工作台，保留可点击的小栏。点小栏可打开常用应用池、进入窗口库或切换手势，无需让工作台一直铺满桌面。

在通过移动工作台进入的兼容窗口中，单指轻滑可以滚动页面。长按约半秒再拖动，松开后轻点一次，就会在选区打开应用自己的右键菜单；从菜单选「复制」。遇到不支持的应用，可以在面板中关闭单指手势，继续使用 UU 原有操作。

本版尚需真机验证 UU 客户端的连续拖动、点位和横竖屏手感。复制由 Windows 应用完成，不涉及读取或同步剪贴板。

升级测试请先正常结束并退出旧版，再完整解压 Windows x64 包、运行新版 `PocketDesk.exe`。
