# PocketDesk v0.2.1 · 手机阅读与应用池（Windows 预发布版）

- 点开小栏，「应用与窗口」同时列出固定应用和正在运行的窗口。点标题即可切换；程序启动后有多个窗口的，也在这里选择。
- 在自动接入的 UU 超级屏上，单指手势可以跟随从 Windows 桌面或任务栏直接打开的前台应用，不必先用应用池接管窗口。需要时可在操作页启用「滚动辅助键」，点 ↑↓ 也能滚动。
- 修复 Windows 版 ChatGPT 的聊天区滚轮可能被投递到外层窗口的问题。小栏显示上一次输入状态，方便核对手机滑动有没有被转成滚轮。
- 从面板进入官方商店版 ChatGPT、Windows Terminal、VS Code 或 Cursor 时，可自动放大一级。ChatGPT 调整整个应用界面。切换窗口或结束工作台时按原有恢复流程撤销；可在「操作」中关闭。

iPhone 17 Pro 经 UU 实测：从小栏进入 Windows 版 ChatGPT 后，聊天正文可以单指上下滚动，界面也会自动放大。

**下载与更新：** 在被控 Windows 电脑上正常结束工作台并退出旧版，下载 `PocketDesk-v0.2.1-win-x64.zip`，完整解压到新目录后运行 `PocketDesk.exe`。压缩包自带 .NET 运行时；可使用附件 `SHA256SUMS` 核对下载。
