# PocketDesk v0.1.0 预发布

PocketDesk 是配合 UU 远程虚拟屏幕使用的 Windows 手机／平板工作台。提供应用选择、窗口整理、手动横竖屏切换、支持应用的字号调整，以及退出时恢复原显示模式和窗口状态。

## 下载与运行

1. 下载 `PocketDesk-v0.1.0-win-x64.zip` 和 `SHA256SUMS`，用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 核对 ZIP。
2. 推荐在 Windows 11 x64 上解压整个目录，运行 `PocketDesk.exe`；其他受 .NET 10 支持的系统尚未全面验证。包内包含 .NET 10 运行时，无需安装 SDK。
3. 安装并配置 UU 远程，在手机或平板连接本机并启用其虚拟屏幕。PocketDesk 不包含 UU 客户端或虚拟显示驱动。

首版没有代码签名，Windows 可能提示未知发布者。请从本仓库的 Releases 页面获取文件，并阅读包内 `README.md`、`docs/user-guide.md` 和许可证。

## 当前范围与限制

- 内置 iPhone 17 Pro 和 iPad Pro 11 英寸（第 3 代）配置；其他型号尚未系统验证。
- 横竖屏由 PocketDesk 工具条手动切换。目前没有可用的手机传感器或 UU“旋转屏幕”按钮事件接口。
- 显示模式受 UU 驱动支持范围限制；理想留边尺寸不可用时，仅使用符合预留条件的枚举模式。窗口最小尺寸、独占全屏或权限差异仍可能影响布局。
- UU 当前控制者识别依赖本机界面。状态不明确时可能需要打开 UU 主界面；无法证明当前会话归属时会保留恢复记录，避免覆盖其他设备的显示设置。
- 自动恢复是尽力恢复，不能保证异常退出、驱动变化或应用自行调整窗口后的所有状态完全一致。

发行流程验证 Windows Release 构建和无需桌面的几何、恢复策略、布局测试。GitHub Actions 不运行交互式 Win32/WPF 窗口测试，也不代替真实 UU 手机／平板联调。详细验证范围见仓库的 `TESTING.md`。
