# 使用指南

[首页](../README.md) · [工作原理](how-it-works.md) · [验证范围](../TESTING.md)

## 开始使用

推荐 Windows 11 x64；其他受 .NET 10 支持的 Windows 版本未全面验证，参见 [Microsoft 兼容表](https://learn.microsoft.com/en-us/dotnet/core/install/windows)。自包含发行包无需另装 .NET。

1. 在 Windows 电脑和手机 / 平板上连接 UU 远程，并启用 UU 超级屏。
2. 完整解压 PocketDesk 的 Windows x64 发行包，运行 `PocketDesk.exe`。
3. 在 UU 手机端选择超级屏，保持设备页的「识别手机和平板」开启。
4. 若无法识别，打开 UU 主窗口，确认「本机被控中」显示当前控制者。PocketDesk 只读该范围，不从同账户设备列表猜测。

目前内置 iPhone 17 Pro 与 iPad Pro 11 英寸（第 3 代）。单个已知型号可从 UU 初始 4K 模式适配；未知型号、可靠 PC 或多个控制者不自动猜测。自动适配开关可以关闭，重启后保留。

## 打开和切换窗口

从 0.2.0 起，手机自动接入后先看到 Windows 桌面。点 PocketDesk 小栏展开面板：竖屏时小栏在工作区底部，横屏时跟随工具栏位置设置。点「应用池」里的应用可以启动程序；也可以添加自己的常用程序。移除条目不会卸载应用。

在 0.2.1 的「应用与窗口」面板中，上方是常用应用，下方是正在运行的窗口。点窗口标题即可切换；更多窗口可以在原处展开和搜索。启动程序后有多个候选窗口时，也在同一个面板选择。

## 单指滚动、拖选与复制（0.2.0）

自动接入后，收起小栏面板，在超级屏上的前台应用内容区操作。从 0.2.1 起，从 Windows 桌面或任务栏打开的普通窗口也可使用手势，无需先从工作台打开。打开 ChatGPT 后，请在聊天正文上滑动；如果 UU 当前控制方式只转发点击，可在小栏「操作」里开启「滚动辅助键」，点 ↑ 或 ↓ 滚动。

1. 手指直接上下滑动可滚动页面。普通轻点仍是左键。
2. 选文字时，按住起点约半秒再拖动，沿引导线拖到终点后松手。此时应能看到应用自己的选区。
3. 再轻点一次，右键菜单会在刚才的选区打开。点应用提供的「复制」即可复制到 Windows 剪贴板。

Windows 端需要收到连续的按下、移动、松开事件。如果 UU 将手势先转换成了别的操作，请尝试可直接点按目标位置的控制方式。应用没有可选文字、使用特殊输入方式或不处理窗口鼠标消息时，展开面板关闭手势，改用 UU 原有控制。手势不作用于整个 Windows 桌面，也不会同步电脑和手机的剪贴板。

## 横竖屏与分辨率

| 操作 | 入口 |
| --- | --- |
| 旋转 | 页头、控制条操作面板、设备设置，或 `Ctrl + Alt + F11` |
| 选择窗口 | 展开小栏中的「应用与窗口」，或按 `Ctrl + Alt + F12` |
| 结束并还原 | 工作台还原入口或控制条操作面板 |

旋转严格互换当前宽高。例如当前 1200×1920 时只请求驱动枚举中的 1920×1200；没有精确目标或无法安全应用则保持当前模式。初次自动竖屏不会在每次手动旋转后强制切回。手机物理转动或 UU 的旋转按钮不一定产生 Windows 信号，应使用 PocketDesk 的入口。

「避让 UU 工具栏」按设备保存。初次适配按竖屏上下边缘或横屏工具栏位置计算完整显示帧；理想尺寸被驱动拒绝时，选择可验证的安全枚举候选。左 / 右侧按居中对称留边计算；可选择底部或已收起，也可以关闭避让。实际 Windows 任务栏属于完整显示帧，程序不单独缩放或移动它。

高级设置可手动选屏、选模式，预览后应在 15 秒内确认；未确认自动回退。手动选择显示器会关闭自动适配，避免自动选择覆盖手动目标。驱动是否支持尺寸由预检与实际读回决定。

## 主题与字号

外观可选自动、浅色、深色。自动读取 Windows 主题偏好；选择保存在本机。内容缩放按设备逻辑宽度和显示 DPI 计算，不修改 Windows 全局 DPI。

0.2.1 的「操作 → 进入应用时放大一级」默认开启。在面板中选择 Windows Terminal、VS Code、Cursor 或官方商店版 ChatGPT 后，PocketDesk 确认窗口在前台才发送该应用的缩放快捷键。ChatGPT 放大整个界面。直接从 Windows 桌面打开只启用手势，不主动改字号。切换窗口或结束工作台时尝试还原；手动字号按钮仍可用。自定义快捷键和权限可能影响结果，若提示字号状态不确定，请在应用内核对。

## 结束、断线与恢复

建议先点击「结束并还原」，再退出 UU 超级屏。手动结束只抑制当前连接自动重开；真实虚拟屏缺席至少 1 秒后重连，或确认旧控制已断开后识别到新的手机或平板连接，都会解除相应抑制。

程序在修改前保存原始窗口与显示状态，多次旋转不覆盖最初快照。正常结束、恢复助手和下次启动都会尝试处理待恢复记录；窗口已变化、显示不可读或身份不符时保留证据。

控制者 Unknown 并不一定表示断连。使用常见备用分辨率的会话，自动恢复会等待新鲜控制者证据，避免覆盖后来接入的 PC；如果 UU 已自行恢复到原显示模式，程序会核对后清理旧显示记录，让下一次连接继续适配。仍在等待时，可打开 UU 主窗口帮助识别，或在界面手动结束。不要为了消除提示直接删除恢复文件。UU 的虚拟屏创建 / 删除和物理屏启用状态不属于 PocketDesk 的还原保证。

0.1.1 已通过 iPhone 直接断开 UU 后重新连接的实机验证，能够再次自动适配竖屏；第三方应用的原位还原仍需更多逐项验证。具体范围见[验证记录](../TESTING.md)。

## 更新与本地数据

首版没有自动更新。先正常结束并退出旧程序，再完整解压新版发行目录；不要混用不同版本的 DLL。自包含版本无需另外安装 .NET。

本地设置位于 Windows 当前用户的 `%LOCALAPPDATA%/PocketDesk/`。这是产品数据目录，不是仓库路径。

| 文件 | 用途 |
| --- | --- |
| `phone.json` | 兼容旧设备资料 |
| `device-preferences.json` | 设备方向和自动适配偏好 |
| `viewport-preferences.json` | 留边设置 |
| `theme.json` | 外观选择 |
| `recovery.json` | 原始窗口 / 显示及模式归属 |
| `diagnostics.log` | 本机诊断 |

恢复记录可能含进程路径、设备身份和窗口位置；诊断可能含设备名称。提交问题前请脱敏。卸载前应先确认恢复完成，再决定是否删除设置目录。
